# 📰 Pulse News - 프리미엄 맞춤형 실시간 뉴스 리더

순수 **HTML5, CSS3, JavaScript(Vanilla JS)**로 구현된 반응형 고품질 웹진 스타일 뉴스 리더입니다.

---

## 🌟 주요 특징 및 구현 내역

### 1. 관심 주제 다중 선택 & 헤드라인 수집
- **비즈니스(Business)**, **스포츠(Sports)**, **문화(Culture/Entertainment)** 주제를 자유롭게 다중 선택/해제할 수 있는 인터랙티브 토글 칩 제공
- **'뉴스 보기'** 클릭 시 선택된 각 주제별 상위 10개의 최신 헤드라인을 실시간으로 수집하여 피드에 추가

### 2. 고신뢰도 무료 뉴스 엔진 (CORS 프리)
- `ok.surf/api/v1/cors/news-feed` 및 Google News KR 오픈 피드를 결합하여, **API 키 발급이나 설정 없이 즉시 100% 동작**
- 기사마다 **실제 고화질 썸네일 이미지(`og`)**와 **언론사 파비콘 아이콘(`source_icon`)**이 기본 제공되어 시각적 퀄리티 극대화
- 필요 시 상단 `⚙️` 버튼을 통해 개인 GNews API 키로 전환할 수 있는 하이브리드 지원

### 3. 끊김 없는 무한 스크롤 (Infinite Scroll)
- **IntersectionObserver** + **Window Scroll 이벤트 이중 안전장치** 적용
- 페이지 하단 350px 전에 미리 감지하여 **추가 10건의 기사를 자동으로 매끄럽게 렌더링**
- 150건 이상의 방대한 피드 풀과 자동 심층 큐레이션 보충 로직으로 스크롤이 끊기지 않고 계속 이어짐

### 4. 세련된 매거진 룩 & 화이트 카드 디자인
- **깔끔한 순백색 카드(`background: #ffffff`)**와 깊이감 있는 세련된 그림자(`box-shadow`)
- 마우스 오버 시 입체적인 리프트 모션(`transform: translateY(-8px)`), 이미지 줌인, 화살표 호버 애니메이션
- 카드가 마운트될 때 부드러운 페이드인 슬라이드업(`fade-slide-up`) 효과
- 디바이스 해상도에 맞춰 모바일(1열), 태블릿(2열), 데스크톱(3열)으로 최적화되는 **반응형 CSS Grid**

### 5. 상세 본문 읽기 모달 뷰어
- 카드의 '읽기' 버튼(또는 카드 클릭)을 누르면 매거진 뷰어 형태의 상세 모달 오픈
- 배경 블러 오버레이(`backdrop-filter: blur(12px)`), 큰 대표 이미지, 언론사 정보, 본문 요약, **원문 기사 보러 가기** 링크 제공
- 닫기 버튼, 배경 오버레이 클릭, 키보드 `ESC` 키로 손쉽게 닫기 가능

## 📂 파일 구조

```

├── index.html           # 프리미엄 매거진 마크업, 글래스모피즘 헤더, 모달 다이얼로그
```
